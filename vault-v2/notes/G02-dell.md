# G02 Dell 2010

## 一句话概括

以殖民劳役区边界切出邻域样本，识别强制劳役对秘鲁县级发展的长期影响。

## 研究设计

- **观测单元** 县与到边界的距离。
- **处理变量** 取县是否落在殖民时期米塔（mita）劳役区之内。
- **结果变量** 取家庭消费、儿童发育迟缓率与土地所有权。
- **识别逻辑** 空间断点回归（spatial regression discontinuity）。边界视为外生分界。线两侧地理条件连续，制度身份在线上跳变。

## 数据结构

- 历史档案边界，空间属性为线，用作断点位置。
- 人口普查与家计调查，空间属性为面，单元为县。
- 县质心到边界线的带符号距离，空间属性为点上的连续变量。
- 地形栅格，用于检验两侧自然条件是否连续。

## 可迁移的做法

1. 把历史地图上的边界数字化成折线，并统一投影。
2. 计算县质心到折线的带符号距离。
3. 在方程中放入距离多项式与边界段固定效应。
4. 用多组带宽重复估计，报告系数随带宽的变动。

## 主要结论

- 劳役区县的长期消费水平更低。
- 劳役区县的儿童发育迟缓率更高。
- 边界邻域的样本使两侧地理条件近似可比。

## 复制这项研究需要注意

- 边界附近的样本有限，估计依赖少数县。
- 边界位置可能内生，两侧差异未必只反映制度。
- 须报告多组带宽下的系数。
