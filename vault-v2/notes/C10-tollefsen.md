# C10 Tollefsen 等 2012

## 一句话概括

统一网格主键与聚合规则，使跨数据源结果可比。

## 研究设计

- **观测单元** 全球零点五度网格。
- **处理变量** 取网格主键与变量聚合规则。
- **结果变量** 取网格层面的多源变量表。
- **识别逻辑** 数据基础设施，主键统一构成跨源连接的前提。

## 数据结构

- 全球网格，空间属性为栅格，单元为格子。
- 事件点，空间属性为点，按坐标落入格子。
- 面状变量，按面积权重聚合到格子。

## 可迁移的做法

1. 建立全球统一的网格主键。
2. 把点事件按坐标落入格子。
3. 把面变量按面积权重聚合。
4. 记录每个变量的来源与年份。

## 主要结论

- 统一主键使跨源合并可以直接执行。
- 面积加权聚合减少边界格子的偏差。

## 复制这项研究需要注意

- 网格与行政边界的错位带来分配误差。
- 不同源的时间分辨率不一致。
