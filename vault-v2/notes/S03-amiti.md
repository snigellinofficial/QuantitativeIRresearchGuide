# S03 Amiti 等 2019

## 一句话概括

估计关税在进口价格上的传递幅度。

## 研究设计

- **观测单元** 进口品—月。
- **处理变量** 取进口品面临的从价关税变动。
- **结果变量** 取进口品的到岸价格。
- **识别逻辑** 关税传递回归，比较税目与月份的价格变动。

## 数据结构

- 进口品与月份，空间属性为面。
- 来源国与目的国，空间属性为关系边。
- 税目表，按品类挂到进口记录。

## 可迁移的做法

1. 把关税变动匹配到进口税目。
2. 控制来源国与品类固定效应。
3. 估计关税对到岸价格的系数。
4. 按来源国分组检验异质性。

## 主要结论

- 关税几乎完全传递到进口价格。
- 传递幅度在来源国之间接近一致。

## 复制这项研究需要注意

- 税目分类变动会造成匹配失败。
- 到岸价格含运输成本，须分离。
