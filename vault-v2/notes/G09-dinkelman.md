# G09 Dinkelman 2011

## 一句话概括

以坡度与到既有电网的距离预测电网落点。

## 研究设计

- **观测单元** 南非农村社区。
- **处理变量** 取社区是否接入电网。
- **结果变量** 取女性就业率与家庭能源使用。
- **识别逻辑** 工具变量由坡度与到既有电网的距离合成，通电概率由此预测。

## 数据结构

- 社区点位，空间属性为点。
- 电网线路，空间属性为线，按年份标注延伸。
- 坡度栅格，空间属性为栅格。

## 可迁移的做法

1. 数字化电网线路并按年份标注延伸。
2. 由地形栅格计算社区坡度。
3. 用坡度与距离预测通电概率。
4. 以预测值估计就业效应。

## 主要结论

- 地形变量预测通电概率，排除限制可检验。
- 通电与女性就业上升并存。

## 复制这项研究需要注意

- 电网延伸记录按行政区归档，点位须核对。
- 坡度工具可能经农业渠道影响就业。
