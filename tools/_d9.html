9.4　第二部分　文献拆解

据前三节的综述，以下三篇按同一线索拆开。三篇分别代表三种处理「冲突数据不可靠」的办法：用价格构造暴露度、把大宗商品分成两类、把不平等拆成两个维度。

拆解一　Bazzi 与 Blattman（2014）：把出口价格编织成一个指数

问题意识。据该文的设定，跨国回归发现「收入低的国家内战多」。但收入低可能是内战的结果，也可能与内战同由一个第三因素驱动。该文不去找收入的工具，而直接问：当一国的出口价格外生上涨时，冲突是否减少。这一问法把「收入」替换成「价格」，因为价格由世界市场决定，不由交战双方决定。

为什么这一替换能成立。价格对单个国家是外生的，但不同国家的出口结构不同，故同一价格变动对各国的影响强度不同。出口结构在短期内不易改变，于是它提供了横截面差异；价格提供了时间差异；两者相乘得到暴露度。这与 7.2 节的份额移动是同一结构。

数据的边界。观测单元取国家—年。数据包括各国出口商品的结构、各类商品的国际价格、冲突事件的发生与否，以及一组国家特征。关键在于出口结构要用基期固定，否则价格变动会反过来改变权重。时间边界须覆盖价格波动的完整周期，太短会把趋势当成冲击。

变量怎样被造出来。第一步，取基期的出口篮子，得到每个国家在各商品上的权重。第二步，对每个国家构造加权价格指数。第三步，取该指数相对长期趋势的偏离，作为经济冲击。第四步，把冲击标准化，使不同国家的系数可比。权重固定、价格外生，这是全套设计的力量来源。

为什么不用更简单的办法。一种替代是直接用人均收入增长，但收入增长受冲突影响，方向相反。另一种替代是用单一商品价格，但多数国家出口多种商品，单一价格无法代表其收入冲击。加权指数同时解决了两件事：外生性与代表性。

$$\mathrm{Shock}_{it}=\sum_{k} w_{ik}\,\Delta\ln P_{kt},\qquad \Pr\!\left(\mathrm{Conflict}_{it}=1\right)=\Lambda\!\left(\alpha+\beta\,\mathrm{Shock}_{it}+\mu_i+\lambda_t\right)$$
拆解一的指数构造与估计方程（简化形式）
符号含义取值或单位在本文中的作用
$i$国家的下标整数编号观测单元
$k$出口商品的下标按国际商品分类编码权重的另一维
$w_{ik}$国家 $i$ 在商品 $k$ 上的出口权重份额，基期固定，合计为 1固定不动的横截面部分
$\Delta\ln P_{kt}$商品 $k$ 在第 $t$ 年的价格对数变动由国际价格序列算出外生的时间部分
$\mathrm{Shock}_{it}$国家 $i$ 的加权价格冲击加权和，正负均可核心解释变量
$\Lambda(\cdot)$逻辑斯蒂分布函数取值 0 到 1把线性预测转成概率
$\beta$价格冲击对冲突概率的影响待估参数核心系数
$\mu_i,\lambda_t$国家与年固定效应—吸收不变因素与全球共同冲击

方程怎么从假设推出来。第一步，写出国家的收入方程，假定收入由出口收入与国内产出构成。第二步，把出口收入写成价格与数量的乘积，取对数变动。第三步，把多项商品的变动按事前份额加权，得到单一指数。第四步，把指数放入冲突方程并加固定效应。第三与第四步之间有一个隐含假设：份额不随冲击改变。若份额随价格变化，指数就内生了。

论证链条。据该文的推进，共有四步。第一步，用固定效应模型估计上式，得到负系数，即价格上涨降低冲突概率。第二步，按收入水平分组，发现效应集中在低收入国家，高收入国家几乎为零。第三步，把冲击拆成正向与负向，发现负向冲击的作用更强。第四步，讨论机制，指向就业机会而非国家能力。第二步是全文的关键，因为「同一冲击在不同国家效应不同」这一事实本身就排除了全球共同趋势的解释。

稳健性与争议。据该文的做法，检验包括：改变权重基期；把冲突定义从「发生与否」换成「死亡人数」；加入国家特定时间趋势。第三项最严格：若加入趋势后系数仍显著，说明结果不是由长期下滑驱动。争议在于价格可能经由粮食价格影响城市暴动，这一渠道不经过收入。

可迁移的三点。第一，把「收入」换成「价格」，是绕开反向因果的常用办法。第二，权重必须固定，否则暴露度内生于结果。第三，分组本身就是识别的一部分，不只是异质性展示。

拆解二　Dube 与 Vargas（2013）：同一种冲击，两种相反的符号

问题意识。据该文的设定，哥伦比亚的冲突与农产品价格有关。但价格冲击对不同作物的影响不该相同。咖啡是劳动密集的小农作物，价格上涨意味着就业机会增加；石油是资本密集的国有资源，价格上涨意味着财政租金增加。前者应降低冲突，后者应提高冲突。该文把这一对立写成可检验的假设。

为什么这一对立重要。若只检验「价格与冲突的关系」，正负两种渠道会互相抵消，得到接近零的系数，结论就成了「无影响」。把商品分类，等于把两个相反的经济机制分开测量。这是全文的立论基础。

数据的边界。观测单元取市镇。数据包括各市镇的作物适种性与石油开采、国际价格序列、凶杀与冲突事件。适种性由地形与土壤决定，不随价格变化，这是横截面部分的外生来源。时间上须覆盖两类商品价格不同步变动的年份，否则两个交互项无法分离。

变量怎样被造出来。第一步，用农业与地质资料构造每个市镇的咖啡适种性与石油储量。第二步，把适种性标准化到 0 至 1 的区间。第三步，把两类暴露度同时放进一个方程。同时放入是关键：两类冲击在时间上相关，分开估计会把彼此的效果算到对方头上。

为什么不用更简单的办法。一种替代是用「咖啡产量占比」，但产量本身受冲突影响。另一种替代是用「是否种植咖啡」，但二值变量丢掉了强度信息。适种性的优势是它只反映自然条件，且在价格变动前就已确定。

$$y_{mt}=\beta_{1}\left(P^{\mathrm{cof}}_{t}\times S_{m}\right)+\beta_{2}\left(P^{\mathrm{oil}}_{t}\times O_{m}\right)+\mu_{m}+\lambda_{t}+\varepsilon_{mt}$$
拆解二的估计方程与符号分配（简化形式）
符号含义取值或单位在本文中的作用
$m$市镇的下标整数编号观测单元
$y_{mt}$该市镇的凶杀率或冲突事件数每十万人或计数结果变量
$P^{\mathrm{cof}}_{t}$第 $t$ 年国际咖啡价格美元每磅，取对数时间维度之一
$S_{m}$该市镇的咖啡适种性0 到 1 的指数横截面维度之一，不随时间变
$P^{\mathrm{oil}}_{t}$第 $t$ 年国际油价美元每桶，取对数时间维度之二
$O_{m}$该市镇是否有石油开采0 或 1横截面维度之二
$\beta_1$咖啡价格冲击的效应待估，预期为负机会成本渠道
$\beta_2$油价冲击的效应待估，预期为正财政租金渠道
$\mu_m,\lambda_t$市镇与年固定效应—吸收适种性与全国趋势

方程怎么从假设推出来。第一步，写出市镇的冲突供给方程，含机会成本与掠夺收益两项。第二步，把机会成本写成农业工资的函数，把农业工资写成作物价格的函数。第三步，把掠夺收益写成财政租金与非法收入的函数。第四步，用适种性与开采状态把两类价格映射到市镇。四步之后，方程里的两个交互项各自对应一条机制，而不是两个统计控制。

论证链条。据该文的推进，共三步。第一步，分别估计两类冲击，发现符号相反。第二步，把两者放进同一方程，符号稳定。第三步，检验渠道：咖啡价格上升时，农业就业与工资上升；油价上升时，公共支出与腐败指标上升。第三步把「符号相反」这一统计事实转成机制证据。

稳健性与争议。据该文的做法，检验包括：改变适种性的阈值；排除受游击队控制较强的市镇；用不同的冲突指标重估。第二项针对的是内生性：若游击队的控制区本身与适种性相关，估计会有偏。争议在于油价影响可能经由地方政治而非财政租金。

可迁移的三点。第一，同一外生冲击可以由不同渠道产生相反效应，故必须分类。第二，两个交互项要同时进入方程。第三，机制检验要落到可观测的价格或就业变量上。

拆解三　Cederman、Weidmann 与 Gleditsch（2011）：把不平等拆成两个维度

问题意识。据该文的设定，「不平等导致冲突」这一说法长期无法检验，原因是「哪一群人与哪一群人比」说不清。该文把比较对象明确为族群与全国平均之间，并把不平等拆成经济与政治两个维度。

为什么必须换观测单元。若以国家为单元，不平等被压缩成一个基尼系数，族群之间的差异被抹平。若以个人为单元，冲突又不是个人行为。族群—年是唯一能同时容纳「群体差异」与「冲突发生」的层级。

数据的边界。观测单元取族群—年。数据包括族群的空间分布多边形、族群的政治地位编码、夜间灯光与家庭资产、冲突事件。族群的空间分布是连接族群与地理的关键：只有把它画成多边形，才能把地理数据聚合到族群。时间边界须覆盖族群政治地位发生变化的年份。

变量怎样被造出来。第一步，把族群分布多边形与行政区求交，得到族群在各行政区的人口份额。第二步，把夜间灯光或资产指数按份额加权，得到族群的平均财富。第三步，用族群平均值除以全国平均值，取对数，得到经济不平等。第四步，从政治地位编码中取「被排除」与「被排斥」两类，得到政治不平等。两个维度分开，是为了检验它们是否各自独立起作用。

为什么不用更简单的办法。一种替代是用族群的语言分化或宗教分化，但这些变量衡量的是「差异」而非「不平等」。另一种替代是用全国基尼系数，但它不区分群体。比值的写法同时保留了方向与幅度，这是它优于分化指数的地方。

$$\Pr\!\left(\mathrm{Onset}_{gt}=1\right)=\Lambda\!\left(\alpha+\beta_{1}\ln\!\left(\frac{W_{gt}}{\bar W_{ct}}\right)+\beta_{2}E_{gt}+\gamma' X_{gt}+\lambda_{t}\right)$$
拆解三的估计方程与符号分配（简化形式）
符号含义取值或单位在本文中的作用
$g$族群的下标编码编号观测单元
$t$年份整数年时间维度
$\mathrm{Onset}_{gt}$该族群在该年是否新卷入武装冲突0 或 1结果变量
$W_{gt}$族群的平均财富灯光或资产指数经济不平等的分子
$\bar W_{ct}$所在国的平均财富同上经济不平等的分母
$\ln\!\left(W_{gt}/\bar W_{ct}\right)$族群相对财富的对数正负均可，负值表示落后经济不平等指标
$E_{gt}$政治排斥的分类变量有序或分类取值政治不平等指标
$\beta_1,\beta_2$两个维度的系数待估核心参数
$\lambda_t$年固定效应—吸收全球冲突周期

方程怎么从假设推出来。第一步，假定冲突的发生取决于群体的相对剥夺感与动员能力。第二步，把相对剥夺写成族群财富与全国平均之比，取对数使比例变化可加。第三步，把动员能力写成政治地位，尤其是是否被排除在行政权力之外。第四步，加入年固定效应吸收全球周期。四步之后，两个系数分别对应「不满」与「机会」，这正是冲突研究的两大理论传统。

论证链条。据该文的推进，共四步。第一步，只放经济不平等，系数为负且显著，即相对落后提高冲突概率。第二步，加入政治排斥，两个维度都显著，说明它们各自独立起作用。第三步，加入交互项，发现政治排斥会放大经济落后的作用。第四步，按地区分组，检验结论是否由非洲驱动。

稳健性与争议。据该文的做法，检验包括：把灯光换成资产调查；改变族群单元的合并规则；排除正在进行的冲突年份。第二项最关键：族群多边形的划分本身带有判断，须证明结论不随划分改变。争议在于灯光与资产可能不反映公共品供给，只反映夜间活动。

可迁移的三点。第一，把「不平等」定义成可计算的比值，是先决条件。第二，两个维度要分别进入，再进入交互。第三，空间多边形是把地理数据接到族群上的唯一通道。
